# บทที่ 2: พจนานุกรมคอนฟิกหลัก (`BuddySettings.json`)

> **[⬅️ บทที่ 1: สถาปัตยกรรมและการติดตั้ง](./01-Architecture-and-Setup.md)** | **[➡️ บทที่ 3: ระบบดาวเทียม ประกันภัย และร้านค้าวิทยุ](./03-DLC-Satellite-and-Insurance.md)**

ไฟล์ตั้งค่าหลักของระบบอยู่ที่:
`$profile:\DayZStory\AiBuddy\BuddySettings.json`

> [!IMPORTANT]
> **หมายเหตุเรื่องค่า Boolean ใน JSON ของ DayZ Enforce Script:**
> ตัวโหลด JSON ของ DayZ (`JsonFileLoader`) ใช้ตัวเลข `1` แทน `true` (เปิดใช้งาน) และ `0` แทน `false` (ปิดใช้งาน) แอดมินควรใส่ค่าเป็น `1` หรือ `0` เสมอ

## 1. หมวดระบบหลักและระบบเศรษฐกิจ (General & Economy Settings)

| ชื่อตัวแปร (Key) | ชนิดข้อมูล | ค่าเริ่มต้น | ตัวเลือกที่รองรับ (Valid Values) | คำอธิบายและเงื่อนไขการทำงาน |
| :--- | :---: | :---: | :--- | :--- |
| `m_SystemEnabled` | `bool` (`0`/`1`) | `1` | `0` = ปิดระบบทั้งหมด<br>`1` = เปิดระบบปกติ | สวิตช์หลักของมอด หากตั้งเป็น `0` ผู้เล่นจะไม่สามารถจ้าง เรียก หรือใช้งานระบบบัดดี้ได้เลย |
| `m_EconomyMode` | `int` | `0` | `0` = **Hardline Reputation** (แต้มชื่อเสียง Expansion)<br>`1` = **eWallet Coins** (เงินในกระเป๋า eWallet)<br>`2` = **Expansion Bank** (เงินในธนาคาร ATM ของ Expansion Market)<br>`3` = **Free** (ฟรีทุกรายการ ไม่หักแต้ม/เงิน) | **สกุลเงินหลักของระบบ** ใช้สำหรับการจ้างบัดดี้ (`m_Cost`), การเช็คเกณฑ์ขั้นต่ำ (`m_RequireMinRep`), การเรียกบัดดี้กลับ (`m_CallBackCost`) และเป็นค่าเริ่มต้นให้กับระบบกู้ของ/ซื้อประกัน/ร้านค้าวิทยุ (หากใน DLC ตั้ง EconomyMode เป็น `-1`) |
| `m_Cost` | `int` | `500` | `0` ขึ้นไป | ค่าจ้างบัดดี้พื้นฐาน (Fallback) กรณีที่บัดดี้ตัวนั้นใน `m_BuddyRoster` ไม่ได้ระบุราคาไว้ |
| `m_RequireMinRep` | `int` | `1000` | `0` ขึ้นไป | ยอดแต้ม/เงินขั้นต่ำที่ผู้เล่นต้องมีในตัวจึงจะปลดล็อกการจ้างบัดดี้ได้ (Fallback) |
| `m_EnableKeybind` | `bool` (`0`/`1`) | `0` | `0` = ปิดปุ่มลัด (ต้องคุยกับ NPC Contractor หรือใช้วิทยุ)<br>`1` = เปิดให้กดปุ่มลัดเปิดหน้าจ้างบัดดี้ได้ทุกที่ | แนะนำให้ตั้งเป็น `0` สำหรับเซิร์ฟเวอร์ Survival เพื่อให้ผู้เล่นต้องเดินทางไปจ้างบัดดี้กับ NPC Contractor ในเซฟโซน |
| `m_EnableCallBackCost` | `bool` (`0`/`1`) | `1` | `0` = เรียกบัดดี้กลับมาหาฟรี<br>`1` = คิดค่าบริการตาม `m_CallBackCost` | กำหนดว่าจะหักเงิน/แต้มหรือไม่ เมื่อผู้เล่นสั่งเรียกบัดดี้ที่หลงทางให้วาปกลับมาหา (`Call AI Back`) |
| `m_CallBackCost` | `int` | `50` | `0` ขึ้นไป | จำนวนเงิน/แต้มที่หักเมื่อเรียกบัดดี้กลับมาหา (มีผลเมื่อ `m_EnableCallBackCost: 1` หรือตั้งใน `DLC/Radio/Setting.json`) |
| `m_EnableRadio` | `bool` (`0`/`1`) | `1` | `0` = ปิดระบบวิทยุใน Core<br>`1` = เปิดใช้งานระบบวิทยุ | สวิตช์อนุญาตให้ใช้วิทยุสื่อสารร่วมกับโมดูล `DayZStory_Buddy_Radio` |
| `m_LoadoutClass` | `string` | `"HumanLoadout.json"` | ชื่อไฟล์ `.json` ในโฟลเดอร์ `ExpansionMod/Loadouts/` | ชุดอุปกรณ์เริ่มต้น (Fallback) กรณีที่บัดดี้ใน `m_BuddyRoster` ไม่ได้กำหนด `m_LoadoutClass` เฉพาะตัว |

## 2. หมวดการจัดการเมื่อผู้เล่นออกเกม ปลดบัดดี้ หรือเสียชีวิต (Lifecycle & Death Modes)

ตัวแปรกลุ่มนี้สำคัญที่สุดในการกำหนดแนวทางของเซิร์ฟเวอร์ (ว่าเซิร์ฟเวอร์ของคุณเป็นแนว Casual, Tactical หรือ Hardcore):

| ชื่อตัวแปร (Key) | ชนิดข้อมูล | ค่าเริ่มต้น | ตัวเลือกที่รองรับ (Valid Values) | คำอธิบายและเงื่อนไขการทำงาน |
| :--- | :---: | :---: | :--- | :--- |
| `m_DeleteAIOnPlayerDisconnect` | `bool` (`0`/`1`) | `1` | `0` = บัดดี้ยืนเฝ้าอยู่ในโลกต่อเมื่อเจ้าของออกเกม<br>`1` = **แนะนำ:** บันทึกเซฟบัดดี้พร้อมของในตัว แล้วลบออกจากโลกทันทีเมื่อเจ้าของออกเกม | การตั้งเป็น `1` ช่วยลดภาระเซิร์ฟเวอร์และป้องกันคนอื่นมาดักยิงบัดดี้ตอนเจ้าของออฟไลน์ เมื่อผู้เล่นเข้าเกมใหม่สามารถกด Recall เรียกบัดดี้กลับมาพร้อมของเดิมได้ฟรี |
| `m_DeleteAIOnPlayerDismiss` | `bool` (`0`/`1`) | `0` | `0` = เมื่อกด Dismiss บัดดี้จะกลายเป็น AI พเนจร (`eAIFactionRoamingBuddy`) เดินในแมพก่อนถูกลบตามเวลา<br>`1` = เมื่อกด Dismiss ให้ลบบัดดี้และไฟล์เซฟทิ้งทันที | เมื่อผู้เล่นกดปุ่ม **`DISMISS COMPANION`** ในเมนู Manage Buddy เป็นการยกเลิกสัญญาจ้างถาวร (ลบไฟล์เซฟ `<steamid>.json`) |
| `m_AutoCleanDismissedAI` | `bool` (`0`/`1`) | `1` | `0` = ไม่ลบ AI พเนจรที่ถูกปลด<br>`1` = ลบ AI พเนจรอัตโนมัติเมื่อครบเวลา `m_AutoCleanDismissedTime` | มีผลเมื่อ `m_DeleteAIOnPlayerDismiss: 0` เพื่อไม่ให้บอทที่ถูกปลดค้างอยู่ในเซิร์ฟเวอร์มากเกินไป |
| `m_AutoCleanDismissedTime` | `int` | `900` | จำนวนวินาที (เช่น `900` = 15 นาที) | ระยะเวลาที่ปล่อยให้บัดดี้ที่ถูก Dismiss เดินพเนจรในโลกก่อนที่ระบบจะลบออกอัตโนมัติ |
| `m_DeleteAIOnPlayerDeath` | `bool` (`0`/`1`) | `1` | `0` = ไม่ลบบัดดี้เมื่อเจ้าของตาย<br>`1` = **แนะนำ:** จัดการบัดดี้ตามโหมด `m_OwnerDeathBuddyMode` เมื่อเจ้าของตาย | ต้องเปิดเป็น `1` เพื่อให้ระบบ `m_OwnerDeathBuddyMode` ทำงานได้อย่างถูกต้องเมื่อผู้เล่นเสียชีวิต |
| `m_OwnerDeathBuddyMode` | `int` | `0` | **`0` = โหมดล็อกดาวเทียม/สุสาน (Satellite / Cemetery Lock - ค่าเริ่มต้น)**<br>**`1` = โหมดปล่อยพเนจรทันที (Release as Roaming AI)**<br>**`2` = โหมดเก็บเซฟรอ Recall ใหม่ (Safe Despawn & Recallable)** | **ตัวแปรหัวใจหลักเมื่อผู้เล่น (เจ้านาย) ตาย:**<br>• **โหมด `0`**: บัดดี้จะถูกเซฟของทั้งหมดและเก็บออกจากโลกทันที สถานะจะถูกล็อก (`OwnerDeadState = 1`) ผู้เล่นเกิดใหม่ต้องไปเคลมของบัดดี้คืนเป็นกล่อง `eAI_SupplyCrate` ที่ **ตู้ดาวเทียม** (หากมีประกัน) หรือไปขุดเอาของคืนที่ **สุสานสัปเหร่อ (Gravedigger)** จากนั้นจึงจ้างบัดดี้ใหม่<br>• **โหมด `1`**: เมื่อผู้เล่นตาย บัดดี้จะไม่ถูกเก็บ แต่จะหลุดจากปาร์ตี้กลายเป็น AI พเนจรยืนอยู่ในจุดเกิดเหตุและถูกลบไฟล์เซฟทันที<br>• **โหมด `2`**: เมื่อผู้เล่นตาย บัดดี้จะถูกเซฟและเก็บออกจากโลกโดย **ไม่ล็อกสถานะ** พอผู้เล่นเกิดใหม่สามารถใช้วิทยุหรือไปที่ตู้ดาวเทียมเพื่อกด **Recall** บัดดี้ตัวเดิมพร้อมของเดิมกลับมาเดินด้วยได้เลย |

## 3. หมวดระบบกู้คืนและประกันภัยดิจิทัล (Satellite Recovery & Digital Insurance)

> [!NOTE]
> หากเซิร์ฟเวอร์ติดตั้งโมดูล **`DayZStory_Buddy_Satellite`** ค่าในไฟล์ `$profile:DayZStory/AiBuddy/DLC/Satellite/Setting.json` จะถูกซิงค์มาทับค่าในหมวดนี้โดยอัตโนมัติ แอดมินสามารถแก้ที่ไฟล์ของ DLC Satellite ได้โดยตรง

| ชื่อตัวแปร (Key) | ชนิดข้อมูล | ค่าเริ่มต้น | ตัวเลือกที่รองรับ (Valid Values) | คำอธิบายและเงื่อนไขการทำงาน |
| :--- | :---: | :---: | :--- | :--- |
| `m_EnableRecoverySystem` | `bool` (`0`/`1`) | `1` | `0` = ปิดระบบซื้อประกันและเคลมของที่ตู้ดาวเทียม (ซ่อนปุ่มประกันในหน้าต่างตู้ดาวเทียมอัตโนมัติ)<br>`1` = เปิดระบบประกันภัยดิจิทัลและการเคลมกล่องสัมภาระ | หากเซิร์ฟเวอร์ต้องการให้กู้ของบัดดี้ผ่านการ **ขุดหลุมศพกับสัปเหร่อ (`Gravedigger`) เท่านั้น** ให้ตั้ง `m_EnableRecoverySystem: 0` หน้าตู้ดาวเทียมจะซ่อนปุ่มประกันภัยและเหลือเฉพาะฟีเจอร์จูนวิทยุ/ร้านค้าวิทยุ |
| `m_RecoveryReputationCost` | `int` | `1000` | `0` ขึ้นไป (`0` = เคลมฟรีไม่เสียค่าธรรมเนียม) | ค่าธรรมเนียมในการกดเคลมกล่องสัมภาระบัดดี้ (`eAI_SupplyCrate`) ที่ตู้ดาวเทียมหรือตอนขุดหลุมศพ |
| `m_RecoveryEconomyMode` | `int` | `-1` | `-1` = ใช้สกุลเงินเดียวกับ `m_EconomyMode` หลัก<br>`0` = Hardline Reputation<br>`1` = eWallet Coins<br>`2` = Expansion Bank<br>`3` = Free | กำหนดสกุลเงินสำหรับจ่ายค่าธรรมเนียมกู้คืนของ (`m_RecoveryReputationCost`) แยกต่างหากได้ |
| `m_InsuranceCost` | `int` | `1000` | `1` ขึ้นไป | ราคาต่อการซื้อกรมธรรม์ประกันภัยดิจิทัล 1 ฉบับ (`PURCHASE DIGITAL POLICY (+1)`) |
| `m_InsuranceEconomyMode` | `int` | `-1` | `-1` = ใช้ตาม `m_EconomyMode` หลัก<br>`0` = Hardline Rep, `1` = eWallet, `2` = Bank, `3` = Free | กำหนดสกุลเงินสำหรับ **ซื้อประกันภัยดิจิทัล** แยกจากสกุลเงินซื้อวิทยุหรือจ้างบัดดี้ได้ (เช่น จ้างบัดดี้ใช้ Hardline Rep แต่ซื้อประกันใช้ eWallet Coins) |
| `m_MaxInsurancePolicies` | `int` | `3` | `0` = ซื้อสะสมได้ไม่จำกัด<br>`1` ขึ้นไป = จำนวนกรมธรรม์สูงสุดที่ผู้เล่นซื้อตุนไว้ได้ | ทุกครั้งที่เคลมกล่องสัมภาระบัดดี้ที่ตู้ดาวเทียม ระบบจะหักประกัน 1 ฉบับ (`-1 Policy`) |
| `m_InsuranceMenuIconPath` | `string` | `"DayZExpansion/Core/GUI/icons/hud/shield_64x64.edds"` | พาธไฟล์ `.edds` หรือ `.paa` | ไอคอนที่แสดงในหน้าต่าง `BUDDY INSURANCE POLICY` บนตู้ดาวเทียม |
| `m_InsuranceHUDIconPath` | `string` | `"DayZExpansion/Core/GUI/icons/hud/persona_64x64.edds"` | พาธไฟล์ `.edds` หรือ `.paa` | ไอคอนสถานะประกันภัยที่แสดงบริเวณมุมขวาล่างของหน้าจอผู้เล่น (เมื่อผู้เล่นมีประกัน `>= 1` ฉบับ) |
| `m_SatelliteTerminalClasses` | `array<string>` | `["DZS_SatelliteTerminal", "Land_Radio_PanelPAS"]` | รายชื่อ ClassName ของวัตถุในเกม | รายชื่อวัตถุที่ผู้เล่นสามารถเดินเข้าไปกดเปิดเมนู **Satellite Emergency Terminal** ได้ (สามารถเพิ่ม ClassName ของคอมพิวเตอร์หรือตู้วิทยุอื่นในแมพได้) |

## 4. หมวดการรักษาบัดดี้ด้วยตัวเอง (Player-to-Buddy Medical Healing)

ใช้เมื่อผู้เล่นเปิดเมนู **Companion Medical Status** (ผ่านวงล้อคำสั่ง) เพื่อกดพันแผลหรือป้อนยา/น้ำอัดลมให้บัดดี้:

| ชื่อตัวแปร (Key) | ชนิดข้อมูล | ค่าเริ่มต้น | คำอธิบายและการทำงาน |
| :--- | :---: | :---: | :--- |
| `m_HealItemBandages` | `array<string>` | `["bandagedressing", "rag", "splint"]` | รายชื่อ ClassName (ตัวพิมพ์เล็กทั้งหมด) ของไอเทมในตัวผู้เล่นที่ใช้กดปุ่ม **`BANDAGE WOUNDS`** เพื่อห้ามเลือดและรักษากระดูกหักให้บัดดี้ |
| `m_HealItemTonics` | `array<string>` | `["sodacan_cola", ..., "epinephrine", "morphine", "salinebagiv", "tetracyclineantibiotics"]` | รายชื่อ ClassName (ตัวพิมพ์เล็กทั้งหมด) ของไอเทมในตัวผู้เล่นที่ใช้กดปุ่ม **`GIVE TONIC / HEAL`** เพื่อเพิ่ม HP และเลือดให้บัดดี้ |
| `m_HealHPBandage` | `float` | `15.0` | ปริมาณพลังชีวิต (HP จากเต็ม 100) ที่บัดดี้ได้รับเพิ่มต่อการกดพันแผล 1 ครั้ง (พร้อมห้ามเลือดทุกแผลและรักษาขาหักทันที) |
| `m_HealHPTonic` | `float` | `35.0` | ปริมาณพลังชีวิต (HP จากเต็ม 100) ที่บัดดี้ได้รับเพิ่มต่อการกดให้ยา/เครื่องดื่มชูกำลัง 1 ครั้ง |
| `m_HealBloodTonic` | `float` | `1000.0` | ปริมาณเลือด (Blood จากเต็ม 5000) ที่บัดดี้ได้รับเพิ่มต่อการกดให้ยา/เครื่องดื่มชูกำลัง 1 ครั้ง |

| `AdminSteamIDs` | `array<string>` | `["76561198242071384"]` | รายชื่อ SteamID64 ของแอดมินที่มีสิทธิ์ใช้คำสั่งรีโหลดคอนฟิกหรือจัดการระบบบัดดี้ |
| `FriendlyList` | `array<string>` | `["eAIFactionPlayerSurvivor", "eAIFactionCivilian", ...]` | รายชื่อคลาส **Expansion AI Faction** ที่เป็นมิตรกับบัดดี้และ NPC นายหน้า/สัปเหร่อ (ดูรายละเอียดเชิงลึกใน **[บทที่ 6](./06-Factions-Coordinates-and-Editor-Guide.md)**) |

## 6. หมวดรายชื่อและความสามารถบัดดี้รายตัว (`m_BuddyRoster` — ครบทั้ง 20 ฟิลด์)

ใน `BuddySettings.json` จะมีอาร์เรย์ `"m_BuddyRoster": [ ... ]` ซึ่งเริ่มต้นมีบัดดี้ให้ **34 ตัวละคร** แอดมินสามารถเพิ่ม ลบ หรือปรับแต่งความเก่ง ราคา และนิสัยการต่อสู้ของบัดดี้แต่ละคนแยกกันได้อย่างอิสระ:

```json
{
  "m_ID": "boris_sniper",
  "m_ClassName": "eAI_SurvivorM_Boris",
  "m_DisplayName": "Boris 'Hawkeye' (Marksman)",
  "m_Role": "Sniper",
  "m_IconPath": "DayZStory_Buddy_GUI/Data/Boris.paa",
  "m_Description": "Former military sharpshooter specialized in long-range overwatch.",
  "m_Cost": 1500,
  "m_RequireMinRep": 2500,
  "m_LoadoutClass": "HumanLoadout.json",
  "m_AccuracyMin": 0.75,
  "m_AccuracyMax": 0.95,
  "m_ThreatDistanceLimit": 400.0,
  "m_NoiseInvestigationDistanceLimit": 200.0,
  "m_MaxFlankingDistance": 80.0,
  "m_SniperProneDistanceThreshold": 120.0,
  "m_DamageMultiplier": 1.2,
  "m_DamageReceivedMultiplier": 0.85,
  "m_ShoryukenChance": 0.0,
  "m_ShoryukenDamageMultiplier": 3.0,
  "m_LootingBehavior": 1
}
```

### ตารางอธิบายตัวแปรทั้ง 20 ตัวใน `BuddyEntryConfig` (`m_BuddyRoster`)

| ชื่อตัวแปร (Key) | ชนิดข้อมูล | ช่วงค่าที่แนะนำ | คำอธิบายและผลลัพธ์ในเกม |
| :--- | :---: | :---: | :--- |
| `m_ID` | `string` | ข้อความไม่ซ้ำกัน เช่น `"boris_sniper"` | **รหัสประจำตัวบัดดี้ (Primary Key)** ห้ามซ้ำกับตัวอื่นใน `m_BuddyRoster` ใช้สำหรับผูกกับไฟล์เซฟผู้เล่นและระบบ Exclusive Hire (1 ตัวละครมีคนจ้างได้ทีละ 1 คนในเซิร์ฟเวอร์) |
| `m_ClassName` | `string` | เช่น `"eAI_SurvivorM_Boris"` | ชื่อคลาสโมเดล AI ของ Expansion (`eAI_SurvivorM_*` หรือ `eAI_SurvivorF_*`) |
| `m_DisplayName` | `string` | เช่น `"Boris 'Hawkeye'"` | ชื่อที่แสดงในการ์ดเลือกจ้างบัดดี้ และเป็นชื่อเริ่มต้นของบัดดี้เมื่อเสกออกมา |
| `m_Role` | `string` | เช่น `"Sniper"`, `"Field Medic"`, `"Breacher"` | สายอาชีพที่แสดงใน UI **สำคัญ:** หากคำใน `m_Role` มีคำว่า `"Medic"` (เช่น `"Field Medic"` หรือ `"Combat Medic"`) โมดูล `DayZStory_Buddy_Medic` จะถือว่าบัดดี้ตัวนี้เป็นสายแพทย์สนาม (ปั๊มหัวใจและพันแผลไวขึ้น!) |
| `m_IconPath` | `string` | `"DayZStory_Buddy_GUI/Data/<Name>.paa"` | พาธรูปโปรไฟล์ของบัดดี้ แสดงทั้งในหน้าจ้างบัดดี้, หน้า Manage Buddy และหน้า Satellite Terminal (มีรูปให้เลือกใช้ 34 คนใน `DayZStory_Buddy_GUI/Data/`) |
| `m_Description` | `string` | ข้อความอธิบาย | ประวัติหรือคำอธิบายจุดเด่นของบัดดี้ แสดงในหน้าต่างเลือกจ้างบัดดี้ |
| `m_Cost` | `int` | `0` ขึ้นไป | **ค่าตัวในการจ้างบัดดี้คนนี้** (หักจากผู้เล่นเมื่อกดปุ่ม Hire) |
| `m_RequireMinRep` | `int` | `0` ขึ้นไป | **เกณฑ์ขั้นต่ำในการปลดล็อก** ผู้เล่นต้องมียอดแต้ม/เงินในตัวไม่ต่ำกว่าค่านี้จึงจะกดปุ่มจ้างบัดดี้คนนี้ได้ |
| `m_LoadoutClass` | `string` | เช่น `"HumanLoadout.json"` | ชื่อไฟล์ชุดและอาวุธเริ่มต้นที่จะสวมใส่ให้บัดดี้ตอนจ้างครั้งแรก |
| `m_AccuracyMin` | `float` | `0.0` ถึง `1.0` | ความแม่นยำในการยิงต่ำสุด (`0.0` = ยิงไม่โดนเลย, `1.0` = แม่น 100%) แสดงใน UI หน้าจ้างบัดดี้ |
| `m_AccuracyMax` | `float` | `0.0` ถึง `1.0` | ความแม่นยำในการยิงสูงสุด (เช่น `0.85` จะแสดงในหน้าจ้างว่า `ACCURACY: ~85%`) |
| `m_ThreatDistanceLimit` | `float` | `50.0` ถึง `600.0` (เมตร) | ระยะสายตาสูงสุดที่บัดดี้จะตรวจจับศัตรูและเริ่มเข้าสู่โหมดต่อสู้ |
| `m_NoiseInvestigationDistanceLimit` | `float` | `50.0` ถึง `400.0` (เมตร) | ระยะที่บัดดี้ได้ยินเสียงปืนหรือเสียงซอมบี้แล้วหันไปตรวจจับเป้าหมาย |
| `m_MaxFlankingDistance` | `float` | `0.0` ถึง `200.0` (เมตร) | ระยะทางสูงสุดที่บัดดี้จะวิ่งอ้อมโอบล้อม (Flank) ศัตรูขณะปะทะ |
| `m_SniperProneDistanceThreshold` | `float` | `0.0` = ปิด<br>`> 0.0` = ระยะเมตร (เช่น `100.0`) | **ความสามารถพิเศษสาย Sniper:** หากศัตรูอยู่ห่างเกินระยะนี้ (เช่นเกิน 100 เมตร) บัดดี้จะทิ้งตัวลง **นอนหมอบยิง (Prone)** โดยอัตโนมัติเพื่อเพิ่มความแม่นยำ |
| `m_DamageMultiplier` | `float` | `0.5` ถึง `3.0` (`1.0` = ปกติ) | ตัวคูณความแรงของกระสุนและหมัดที่บัดดี้ทำใส่ศัตรู (เช่น `1.25` = ยิงแรงขึ้น 25%) |
| `m_DamageReceivedMultiplier` | `float` | `0.1` ถึง `2.0` (`1.0` = ปกติ) | ตัวคูณความเสียหายที่บัดดี้ได้รับเมื่อถูกโจมตี **ค่ายิ่งต่ำยิ่งอึด** (เช่น `0.7` = รับดาเมจเพียง 70% เหมาะกับสาย Tank/Breacher, `0.0` = อมตะ) |
| `m_ShoryukenChance` | `float` | `0.0` ถึง `1.0` (เช่น `0.05` = 5%) | โอกาสที่บัดดี้จะใช้ท่าหมัดเสยคางพิเศษ (Shoryuken) เมื่อต่อสู้ระยะประชิด |
| `m_ShoryukenDamageMultiplier` | `float` | `1.0` ถึง `10.0` (`3.0` = 3 เท่า) | ตัวคูณความแรงเมื่อติดท่าหมัด Shoryuken |
| `m_LootingBehavior` | `int` | `0`, `1`, `2`, `3` | **นิสัยการเก็บของอัตโนมัติจากศพ/พื้น:**<br>• `0` = ไม่เก็บของเองเลย<br>• `1` = เก็บเฉพาะอาวุธและกระสุน<br>• `2` = เก็บเฉพาะยาและเวชภัณฑ์<br>• `3` = เก็บทุกอย่างที่ดีกว่าของที่มีอยู่ (`ALL`) |
