## 1. ระบบ NPC นายหน้าว่าจ้างบัดดี้ (`DLC/Contractors/Setting.json`)

จัดการโดย `DayZStory_Buddy_Core` ใช้สำหรับสปอน NPC นายหน้าประจำเซฟโซนเพื่อให้ผู้เล่นเดินเข้าไปกดเปิดหน้าต่างเลือกจ้างบัดดี้ (`BuddyMenu`):

| ชื่อตัวแปร (Key) | ชนิดข้อมูล | ค่าเริ่มต้น | ตัวเลือก / คำอธิบายการทำงาน |
| :--- | :---: | :---: | :--- |
| `Enable` | `bool` (`0`/`1`) | `1` | `1` = สปอน NPC นายหน้าตามรายการ `Contractors`, `0` = ปิดการสปอนทั้งหมด |
| `IsPassive` | `bool` (`0`/`1`) | `0` | • `0` = NPC นายหน้าจะช่วยยิงซอมบี้หรือป้องกันตัวเมื่อมีภัยคุกคาม<br>• `1` = **โหมดสงบ 100% (Passive)** ยืนประจำจุดอย่างเดียว ไม่ชักปืนยิงใครเลย (เหมาะกับ Safezone ที่มีระบบ Godmode อยู่แล้ว) |
| `SpawnRadius` | `float` | `5.0` | รัศมีรอบจุดสปอน (เมตร) |
| `EditorJsonFiles` | `array<string>` | `[]` | รายชื่อไฟล์ `.json` ที่ส่งออกจาก **DayZ Editor** และวางไว้ในโฟลเดอร์ `$profile:DayZStory/AiBuddy/DLC/Contractors/Scenes/` (หรือโฟลเดอร์ `Contractors/`)<br>• หากปล่อยว่าง `[]`: ระบบจะเสกเฉพาะรายการใน `Contractors[]` ที่มีพิกัด `Position`<br>• หากใส่ชื่อไฟล์: ระบบจะเสกทั้งพร็อพตกแต่งฉาก (`.p3d` / Object) และหากในไฟล์ Editor มีการวางคลาสตัวละคร `eAI_*` ไว้ ระบบจะเสกเป็น **NPC Contractor** พร้อมใส่ Faction, อมตะ, `Loadout` และ `EmoteID` (ดึงค่าแม่แบบจาก `Contractors[0]`) ให้อัตโนมัติ! |
| `Contractors[].Name` | `string` | `"Buddy Contractor"` | ชื่อของ NPC นายหน้า (และใช้เป็นชื่อเริ่มต้นให้กับ NPC ที่เสกจาก `EditorJsonFiles` หากใน Editor ไม่ได้ตั้ง `customString`) |
| `Contractors[].Position` | `[x, y, z]` | `[5120.0, 0.0, 5120.0]` | **พิกัด精确 (Exact 3D Position)** ที่วาง NPC นายหน้า (ระบบจะวางตามค่า X, Y, Z ที่กรอกโดยตรง สามารถวางบนชั้น 2 ของอาคารหรือบนพื้นไม้ได้โดยไม่จมดิน) หากเป็น `[0, 0, 0]` จะข้ามไม่สปอน |
| `Contractors[].Orientation` | `[yaw, pitch, roll]` | `[0.0, 0.0, 0.0]` | ทิศทางที่ NPC หันหน้า (มุม Yaw `0` - `360` องศา) |
| `Contractors[].Loadout` | `string` | `"HumanLoadout"` | ชื่อไฟล์ชุดแต่งกายของ NPC จาก `ExpansionMod/Loadouts/` (ใส่แบบมีหรือไม่มี `.json` ก็ได้) |
| `Contractors[].ClassName` | `string` | `"eAI_SurvivorM_Boris"` | คลาสตัวละคร AI ของ Expansion (`eAI_SurvivorM_*` / `eAI_SurvivorF_*`) |
| `Contractors[].EmoteID` | `int` | `0` | รหัสท่าทางของ NPC เมื่อยืนว่าง (`0` = ยืนปกติ, หากใส่รหัสท่าทาง เช่น ท่านั่งเก้าอี้หรือพิงกำแพง ระบบจะรอ 15 วินาทีหลังเสกเพื่อให้ใส่ชุดเสร็จแล้วสั่งเล่นท่าทางนั้นอัตโนมัติ) |

## 2. ระบบสัปเหร่อและสุสานขุดกู้ของบัดดี้ (`DLC/Gravedigger/Setting.json`)

จัดการโดย `DayZStory_Buddy_Gravedigger` เป็นทางเลือกแนว Survival / Immersive สำหรับการกู้คืนสัมภาระบัดดี้เมื่อบัดดี้ตายหรือเจ้านายตาย (ใช้ร่วมกับตู้ดาวเทียม หรือใช้แทนตู้ดาวเทียมได้):

### ขั้นตอนการเล่นของผู้เล่นที่สุสานสัปเหร่อ:
1. เมื่อของบัดดี้ติดสถานะรอกู้คืน ผู้เล่นเดินทางไปหา **NPC สัปเหร่อ (Cemetery Gravedigger)**
2. กดขอยืมพลั่วสัปเหร่อ (`Borrow Gravedigger's Shovel`) ซึ่งจะได้ไอเทมพิเศษ `DZS_GravediggerShovel`
3. เดินไปที่หลุมศพ (`DZS_BuddyGrave`) ในรัศมีสุสาน แล้วถือพลั่วกดขุดหลุมศพ (`Dig Up Companion's Belongings`)
4. เมื่อขุดสำเร็จ ระบบจะหักค่าธรรมเนียมกู้คืน เสกกล่อง **`eAI_SupplyCrate`** ที่บรรจุของบัดดี้ทั้งหมดขึ้นมาบนหลุมศพ และลบไฟล์เซฟบัดดี้เดิมทันที (ป้องกันการขุดซ้ำ/Dupe)
5. **ระบบป้องกันขโมยพลั่ว:** หากผู้เล่นเดินถือพลั่ว `DZS_GravediggerShovel` ออกนอกรัศมี `CemeteryRadius` พลั่วจะถูกลบคืนสัปเหร่ออัตโนมัติ

### ตารางตัวแปรใน `DLC/Gravedigger/Setting.json`

| ชื่อตัวแปร (Key) | ชนิดข้อมูล | ค่าเริ่มต้น | ตัวเลือก / คำอธิบายการทำงาน |
| :--- | :---: | :---: | :--- |
| `Enable` | `bool` (`0`/`1`) | `1` | `1` = เปิดระบบสัปเหร่อและสุสาน, `0` = ปิดระบบทั้งหมด |
| `IsPassive` | `bool` (`0`/`1`) | `0` | `1` = สัปเหร่ออยู่ในโหมดสงบ 100% ไม่ยิงใครเลย, `0` = ยิงซอมบี้ป้องกันตัวตามปกติ |
| `CemeteryRadius` | `float` | `60.0` | **รัศมีเขตสุสาน (เมตร)** วัดจากตัว NPC สัปเหร่อ หากผู้เล่นนำพลั่วที่ยืมมา (`DZS_GravediggerShovel`) ออกนอกระยะนี้ พลั่วจะถูกยึดคืนอัตโนมัติ |
| `DiggingTime` | `float` | `6.0` | ระยะเวลาในการออกท่าขุดหลุมศพ (วินาที) |
| `RecoveryReputationCost` | `int` | `1000` | ค่าธรรมเนียมที่หักเมื่อขุดหลุมศพกู้คืนกล่องสัมภาระสำเร็จ (`0` = ขุดฟรี) |
| `RecoveryEconomyMode` | `int` | `-1` | สกุลเงินที่ใช้จ่ายค่าขุดกู้ของ (`-1` = ตาม `BuddySettings.json`, `0` = Hardline Rep, `1` = eWallet, `2` = Bank, `3` = Free) |
| `ShovelBorrowCost` | `int` | `250` | ค่ายืมพลั่วจาก NPC สัปเหร่อ (`0` = ยืมฟรี) |
| `ShovelEconomyMode` | `int` | `-1` | สกุลเงินที่ใช้จ่ายค่ายืมพลั่ว (`-1` = ตาม `BuddySettings.json`, `0` = Hardline Rep, `1` = eWallet, `2` = Bank, `3` = Free) |
| `EditorJsonFiles` | `array<string>` | `[]` | รายชื่อไฟล์ `.json` ที่ส่งออกจาก **DayZ Editor** และนำมาวางไว้ในโฟลเดอร์ `$profile:DayZStory/AiBuddy/DLC/Gravedigger/Graves/` (เช่น `["cemetery_chernogorsk.json"]`) ระบบจะเสกทั้งพร็อพตกแต่งสุสาน, หลุมศพ `DZS_BuddyGrave` (Target ขุดของ) และหากมีการวางคลาสตัวละคร `eAI_*` ในไฟล์ Editor ก็จะถูกเสกเป็น **NPC สัปเหร่อ** พร้อม Faction/Loadout/EmoteID (ดึงแม่แบบจาก `Gravediggers[0]`) ให้อัตโนมัติ! |
| `Graves[]` | `array<object>` | `[{Position, Orientation, ClassName}]` | พิกัดหลุมศพ `DZS_BuddyGrave` ที่ต้องการวางเพิ่มด้วยการกรอกพิกัดเอง (หาก `Position` เป็น `[0,0,0]` จะข้ามไม่สปอน) |
| `Gravediggers[]` | `array<object>` | `[{Name, Position, Orientation, Loadout, ClassName, EmoteID}]` | รายการจุดสปอน NPC สัปเหร่อ (โครงสร้างเดียวกับ `Contractors[]` ทุกประการ หาก `Position` เป็น `[0,0,0]` จะข้ามไม่สปอน) |

## 3. ระบบวิทยุสื่อสารพกพา (`DLC/Radio/Setting.json`)

จัดการโดย `DayZStory_Buddy_Radio` กำหนดเงื่อนไขการใช้วิทยุสื่อสารในมือผู้เล่น:

| ชื่อตัวแปร (Key) | ชนิดข้อมูล | ค่าเริ่มต้น | ตัวเลือก / คำอธิบายการทำงาน |
| :--- | :---: | :---: | :--- |
| `Enable` | `bool` (`0`/`1`) | `1` | `1` = เปิดใช้งานคำสั่งบัดดี้บนวิทยุพกพา, `0` = ปิดระบบวิทยุพกพา |
| `EnableCallConstructorsMenu` | `bool` (`0`/`1`) | `0` | • `0` = **แนะนำ:** ห้ามเปิดหน้าต่างเลือกจ้างบัดดี้ผ่านวิทยุ (ผู้เล่นต้องเดินไปคุยกับ NPC Contractor เพื่อจ้างบัดดี้เท่านั้น)<br>• `1` = อนุญาตให้ถือวิทยุแล้วกดเปิดหน้าต่างจ้างบัดดี้ (`Recruit AI`) จากที่ไหนก็ได้ |
| `EnableDirectRadioRecall` | `bool` (`0`/`1`) | `1` | • `1` = อนุญาตให้กดเรียกบัดดี้ที่เซฟไว้ (`Recall Buddy`) ผ่านวิทยุในมือได้โดยตรง (เมื่อวิทยุผ่านการ Pair แล้ว และบัดดี้ไม่ได้ติดล็อกการตาย)<br>• `0` = ห้ามกด Recall ผ่านวิทยุพกพาในมือ (บังคับให้ผู้เล่นต้องเดินไปกด Recall ที่ **ตู้ดาวเทียม** เท่านั้น!) |
| `EnableCallBackCost` | `bool` (`0`/`1`) | `1` | `1` = คิดค่าบริการเมื่อสั่งเรียกบัดดี้ที่หลงทางให้วาปกลับมาหา (`Call AI Back`), `0` = เรียกกลับมาหาฟรี |
| `CallBackCost` | `int` | `50` | จำนวนแต้ม/เงินที่หักเมื่อกด `Call AI Back` ผ่านวิทยุ |
| `RequireRadioPairing` | `bool` (`0`/`1`) | `1` | • `1` = **บังคับจูนคลื่น (Pair Radio):** ผู้เล่นต้องถือวิทยุที่เปิดเครื่องไปกด **`PAIR RADIO`** ที่ตู้ดาวเทียมให้สำเร็จก่อน (1 ครั้งต่อ 1 ชีวิตตัวละคร) จึงจะใช้วิทยุเรียกบัดดี้ได้<br>• `0` = ไม่ต้อง Pair วิทยุ เก็บวิทยุใส่ถ่านเปิดเครื่องแล้วกดเรียกบัดดี้ได้ทันที |
| `AllowedRadioClasses` | `array<string>` | `[]` | รายชื่อ ClassName ของวิทยุที่อนุญาตให้ใช้กับระบบบัดดี้:<br>• หากปล่อยว่าง `[]`: รองรับวิทยุทุกชนิดในเกมที่สืบทอดจาก `TransmitterBase` (เช่น `PersonalRadio`, `BaseRadio`)<br>• หากระบุชื่อคลาส เช่น `["PersonalRadio"]`: จะใช้ได้เฉพาะรุ่นที่ระบุเท่านั้น |

## 4. ระบบบัดดี้แพทย์สนามอัตโนมัติ (`DLC/Medic/Setting.json`)

จัดการโดย `DayZStory_Buddy_Medic` เมื่อผู้เล่นบาดเจ็บหรือสลบ บัดดี้จะวิ่งเข้ามาคุกเข่าเล่นอนิเมชั่นรักษาให้โดยอัตโนมัติ (ตามลำดับความสำคัญ: **ปลุกสลบ CPR > พันแผลห้ามเลือด Bandage > ดามเฝือกขาหัก Splint**):

| ชื่อตัวแปร (Key) | ชนิดข้อมูล | ค่าเริ่มต้น | ตัวเลือก / คำอธิบายการทำงาน |
| :--- | :---: | :---: | :--- |
| `Enable` | `bool` (`0`/`1`) | `1` | `1` = เปิดระบบบัดดี้ช่วยรักษาผู้เล่นอัตโนมัติ, `0` = ปิดระบบ |
| `OnlyMedicRole` | `bool` (`0`/`1`) | `0` | • `0` = **บัดดี้ทุกสายอาชีพช่วยรักษาเจ้านายได้** แต่บัดดี้ที่มีคำว่า `"Medic"` ใน `m_Role` จะรักษาเร็วกว่าและมี Cooldown สั้นกว่า<br>• `1` = **เฉพาะบัดดี้สาย Medic เท่านั้น** ที่จะวิ่งมารักษาเจ้านาย สายอาชีพอื่นจะยิงคุ้มกันอย่างเดียว |
| `RequireItems` | `bool` (`0`/`1`) | `1` | • `1` = **สมจริง:** การพันแผลต้องมี `BandageDressing` หรือ `Rag` ในกระเป๋าของบัดดี้ และการดามขาต้องมี `Splint` ในกระเป๋าของบัดดี้ (ใช้แล้วลดจำนวน/หายไปจริง) ส่วน **การปั๊มหัวใจ CPR ทำได้ฟรีเสมอ** (แต่ถ้าในกระเป๋าบัดดี้มีเข็ม `Epinephrine` บัดดี้จะดึงเข็มมาฉีดปลุกให้ตื่นทันทีด้วยความเร็วสูงและได้ Shock เต็ม 100!)<br>• `0` = บัดดี้พันแผลและดามขาให้ฟรีโดยไม่ต้องมีไอเทมในกระเป๋าบัดดี้ |
| `CheckIntervalSeconds` | `float` | `2.0` | ความถี่ในการตรวจสอบอาการบาดเจ็บของเจ้าของ (วินาที ขั้นต่ำ `0.5`) |
| `MaxAssistDistance` | `float` | `40.0` | ระยะห่างสูงสุด (เมตร) ที่บัดดี้จะรับรู้และวิ่งเข้ามาช่วยรักษา |
| `ThreatThreshold` | `float` | `0.4` | ระดับภัยคุกคามสูงสุด (`0.0` - `1.0`) ที่บัดดี้ยอมละจากการยิงปะทะเพื่อมารักษา (หมายเหตุ: หากเจ้านายทั้ง **สลบและเลือดไหล** พร้อมกัน บัดดี้จะยอมเสี่ยงตายเพิ่มขึ้นถึงระดับ `0.75` เพื่อรีบมาปั๊มหัวใจ!) |
| `CPRCooldownSeconds` | `float` | `180.0` | ระยะเวลา Cooldown (วินาที) ในการปลุกสลบของบัดดี้สายอาชีพทั่วไป (`180` = 3 นาทีต่อครั้ง) |
| `MedicCPRCooldownSeconds` | `float` | `90.0` | ระยะเวลา Cooldown (วินาที) ในการปลุกสลบของบัดดี้สาย **Medic** (`90` = 1.5 นาทีต่อครั้ง) |
| `ActionDurationSeconds` | `float` | `5.0` | ระยะเวลาที่บัดดี้สายทั่วไปคุกเข่าทำแผล/ปั๊มหัวใจ (วินาที) |
| `MedicActionDurationSeconds` | `float` | `3.0` | ระยะเวลาที่บัดดี้สาย **Medic** คุกเข่าทำแผล/ปั๊มหัวใจ (วินาที — หากมีเข็ม Epinephrine จะเร็วขึ้นอีก 40%) |
| `EnableCPR` | `bool` (`0`/`1`) | `1` | `1` = อนุญาตให้บัดดี้ช่วยปั๊มหัวใจ / ฉีด Epinephrine เมื่อเจ้าของสลบ |
| `EnableBandage` | `bool` (`0`/`1`) | `1` | `1` = อนุญาตให้บัดดี้ช่วยพันแผลห้ามเลือดให้เจ้าของ |
| `EnableSplint` | `bool` (`0`/`1`) | `1` | `1` = อนุญาตให้บัดดี้ช่วยดามเฝือกขาหักให้เจ้าของ |

## 5. ระบบแสดงผล 3D Marker และไอคอนประกันภัย (`DLC/HUD/Setting.json`)

จัดการโดย `DayZStory_Buddy_HUD` ซิงค์ค่าจากเซิร์ฟเวอร์ไปยังผู้เล่นทุกคนอัตโนมัติ:

| ชื่อตัวแปร (Key) | ชนิดข้อมูล | ค่าเริ่มต้น | ตัวเลือก / คำอธิบายการทำงาน |
| :--- | :---: | :---: | :--- |
| `Enable` | `bool` (`0`/`1`) | `1` | `1` = เปิดแสดงผล 3D Marker บนหัวบัดดี้, `0` = ซ่อน 3D Marker บนหัวบัดดี้ทั้งหมด |
| `HUDType` | `int` | `2` | • `1` = ใช้ 3D Marker ดั้งเดิมของระบบ Expansion Party<br>• `2` = **แนะนำ:** ใช้ Custom 3D Marker ขนาดกะทัดรัด (16px) ของ BuddySystem พร้อมระบบเช็คกำแพงบังสายตา (LOS Raycast) |
| `MaxDistance` | `float` | `150.0` | ระยะทางสูงสุด (เมตร) ที่จะแสดง 3D Marker บนหัวบัดดี้ (และจะซ่อนอัตโนมัติเมื่อเดินเข้าใกล้บัดดี้ในระยะ 1.5 เมตรเพื่อไม่ให้เกะกะหน้าจอ) |
| `ShowIcon` | `bool` (`0`/`1`) | `1` | `1` = แสดงไอคอนสัญลักษณ์บนหัวบัดดี้ |
| `MarkerIconPath` | `string` | `""` | พาธไฟล์ไอคอน `.edds` บนหัวบัดดี้ (หากปล่อยว่าง `""` จะใช้ไอคอนมาตรฐาน หรือใส่ `"DayZStory_Buddy_HUD/GUI/Icons/buddy.edds"`) |
| `ShowName` | `bool` (`0`/`1`) | `1` | `1` = แสดงชื่อของบัดดี้บน 3D Marker |
| `ShowDistance` | `bool` (`0`/`1`) | `1` | `1` = แสดงตัวเลขระยะห่างเป็นเมตร (เช่น `24m`) |
| `LOSCheck` | `bool` (`0`/`1`) | `1` | `1` = **เปิดเช็คสิ่งกีดขวางสายตา (Line-of-Sight Raycast):** หากบัดดี้หลบอยู่หลังกำแพง หลังหิน หรือหลังเนินเขา ระบบจะซ่อน 3D Marker บนหัวบัดดี้ทันทีเพื่อความสมจริง |
| `PartyMarkerLOSCheck` | `bool` (`0`/`1`) | `1` | `1` = ใช้ระบบเช็คกำแพงบังสายตา (LOS Raycast) กับ 3D Marker ของเพื่อนร่วมปาร์ตี้ที่เป็นผู้เล่นคนอื่นด้วย (แต่ยังคงเห็นจุดในแผนที่ 2D ตามปกติ) |
| `ShowBuddyInPartyHUD` | `bool` (`0`/`1`) | `1` | `1` = แสดงชื่อและหลอดเลือดของบัดดี้ในแถบรายชื่อปาร์ตี้มุมซ้ายบนของจอ, `0` = ซ่อนบัดดี้ออกจากแถบปาร์ตี้มุมซ้ายบน |
| `InsuranceIconPath` | `string` | `"DayZExpansion/Core/GUI/icons/hud/persona_64x64.edds"` | พาธไอคอนประกันภัยดิจิทัลที่แสดงมุมขวาล่างของจอ (เหนือไอคอน Hardline) |
| `InsuranceHUD_Position_X` | `float` | `0.0` | ตำแหน่งแกน X ของไอคอนประกันภัย (วัดจากขอบขวาล่างของหน้าจอเป็นพิกเซล) |
| `InsuranceHUD_Position_Y` | `float` | `65.0` | ตำแหน่งแกน Y ของไอคอนประกันภัย (วัดจากขอบขวาล่างของหน้าจอเป็นพิกเซล ตั้งไว้ที่ `65.0` เพื่อให้อยู่เรียงต่อกับไอคอนของ Expansion พอดี) |

## 6. ระบบรางวัลและบทลงโทษทางเศรษฐกิจ (`DLC/Economy/Setting.json`)

จัดการโดย `DayZStory_Buddy_Economy`:

| ชื่อตัวแปร (Key) | ชนิดข้อมูล | ค่าเริ่มต้น | คำอธิบายและการทำงาน |
| :--- | :---: | :---: | :--- |
| `Enable` | `bool` (`0`/`1`) | `1` | `1` = เปิดระบบแจกแต้มรางวัลและค่าปรับของบัดดี้, `0` = ปิดทั้งหมด |
| `RewardKillZombie` | `int` | `2` | แต้ม/เงินรางวัลที่เจ้าของได้รับเมื่อบัดดี้สังหารซอมบี้ 1 ตัว |
| `RewardKillAnimal` | `int` | `5` | แต้ม/เงินรางวัลที่เจ้าของได้รับเมื่อบัดดี้ช่วยล่าสัตว์ป่า 1 ตัว |
| `RewardKillPlayerAI` | `int` | `50` | แต้ม/เงินรางวัลที่เจ้าของได้รับเมื่อบัดดี้สังหารบอทศัตรูหรือผู้เล่นศัตรู 1 คน |
| `PenaltySystemEnabled` | `bool` (`0`/`1`) | `1` | `1` = เปิดระบบหักแต้มเมื่อผู้เล่นยิงบัดดี้, `0` = ปิดการหักแต้ม |
| `PenaltyKillOwnBuddy` | `int` | `500` | จำนวนแต้มที่หักจากผู้เล่น เมื่อผู้เล่น **ฆ่าบัดดี้ของตัวเอง (ทรยศ)** |
| `PenaltyKillStrangerBuddy` | `int` | `300` | จำนวนแต้มที่หักจากผู้เล่น เมื่อผู้เล่นไปฆ่าบัดดี้ของผู้เล่นคนอื่น |

## 7. ระบบควบคุมวงล้อคำสั่ง (`DLC/Controller/Setting.json`) และสิทธิ์แอดมิน (`cfggameplay.json`)

### 7.1 `DLC/Controller/Setting.json` (`DayZStory_Buddy_Controller`)
| ชื่อตัวแปร (Key) | ชนิดข้อมูล | ค่าเริ่มต้น | ตัวเลือก / คำอธิบายการทำงาน |
| :--- | :---: | :---: | :--- |
| `Enable` | `bool` (`0`/`1`) | `1` | `1` = เปิดระบบควบคุมคำสั่งบัดดี้ |
| `RadialMenuType` | `int` | `0` | • `0` = **Auto-detect / Expansion AI** (ตรวจจับอัตโนมัติหรือใช้วงล้อ `eAICommandMenu` ของ Expansion)<br>• `1` = บังคับใช้วงล้อของมอด `DayZStory_RadialMenu` |
| `EnableQuickCommand` | `bool` (`0`/`1`) | `1` | `1` = เปิดใช้งานปุ่มคำสั่งด่วน |

### 7.2 การตั้งสิทธิ์แอดมินผ่าน `cfggameplay.json` (`DayZStory_Buddy_Admin`)
นอกจากการใส่ SteamID64 ใน `"AdminSteamIDs"` ของ `BuddySettings.json` แล้ว หากติดตั้ง `DayZStory_Buddy_Admin.pbo` แอดมินสามารถเพิ่มอาร์เรย์ `"BuddyAdmins"` ลงในหมวด `"PlayerData"` ของไฟล์ `mpmissions/<mission>/cfggameplay.json` ได้ด้วย:

```json
"PlayerData": {
    "disablePersonalLight": false,
    "BuddyAdmins": [
        "76561198242071384"
    ]
}
```
